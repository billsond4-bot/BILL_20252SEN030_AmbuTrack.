# Data Folder

## Project Title

**Online Job Recruitment and Applicant Tracking System**

---

## Purpose

This folder stores the datasets used for developing and testing the Online Job Recruitment and Applicant Tracking System.

The data will be used to design the database, populate Oracle tables, test SQL and PL/SQL programs, and generate reports.

---

## Dataset Information

**Dataset Name:** LinkedIn Job Postings Dataset

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/arshkon/linkedin-job-postings

---

## Dataset Description

The dataset contains real-world job posting information collected from LinkedIn. It includes recruitment-related data that can be used to design and test the database.

The dataset contains information such as:

- Job Title
- Company Name
- Company Industry
- Job Location
- Employment Type
- Job Description
- Required Skills
- Experience Level
- Salary (where available)

---

## Purpose of the Dataset

The dataset will be used to:

- Design database tables.
- Normalize recruitment data.
- Populate Oracle Database tables.
- Test SQL queries.
- Develop PL/SQL procedures, functions, triggers, and packages.
- Generate recruitment reports.

---

## Data Preparation

Before importing the dataset into Oracle Database, the following steps will be completed:

- Remove duplicate records.
- Handle missing values.
- Standardize column names.
- Normalize the data into relational tables.
- Validate the data before testing.

---

## Planned Tables

The dataset will support the following tables:

- Employers
- Applicants
- Jobs
- Applications
- Interviews
- Skills
- Departments
- Notifications
